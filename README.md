## Currently

- **Auto Dev Crew**: a local AI coding agent. It takes work from GitHub issues labelled `ai-task`, opens pull requests, and scans the code for improvements when no issues are waiting. Experimental.

## Featured projects

- [**Auto Dev Crew**](https://github.com/OkayOkay101/auto-dev-crew-clean): local agent that turns labelled issues into pull requests. Python 3.12, pytest, and a local web GUI.
- [**BattleFight**](https://github.com/OkayOkay101/BattleFightLegacy): top-down team arena game built on the Taro engine. Runs from source with `npm`, and has an offline Windows build.
- [**Cyberpunk Focus Pomodoro**](https://github.com/OkayOkay101/cyberpunk-pomodoro): a neon Pomodoro timer with generated ambient sound. Runs in the browser with no build step. [Live demo](https://okayokay101.github.io/cyberpunk-pomodoro/)
- [**Load Profile & TOU Simulator**](https://github.com/OkayOkay101/DATAelectricWORKs): upload electricity load data and compare time-of-use and single-rate costs in a Streamlit app.
- [**Codex Config Guard**](https://github.com/OkayOkay101/codex-config-guard): Windows tool that checks and restores the Codex `config.toml` automatically.
